## التثبيت على أندرويد

يتم بناء ملف APK تلقائيًا بواسطة GitHub Actions عند رفع تعديل إلى المستودع.

1. افتح صفحة [عمليات البناء](../../actions/workflows/android.yml).
2. اختر أحدث عملية بناء ناجحة.
3. من قسم **Artifacts** نزّل `enjazi-apk`.
4. فك ضغط الملف وثبّت APK على جهاز Android.

> لا توجد في إعدادات Workflow الحالية خطوة تنشر APK تلقائيًا داخل GitHub Releases؛ لذلك استخدم Artifact من عملية البناء.

## تجربة المشروع

يمكنك فتح [المستودع على GitHub](https://github.com/jacksparo2000m-stack/ENJAZI) لمراجعة الملفات والمصدر. لا نفترض أن نسخة GitHub Pages منشورة ما لم يتم إعدادها والتحقق منها.

## ما الذي يقدمه التطبيق؟

- **قائمة المهام:** تاريخ ووقت، أولويات، تصنيفات، مهام فرعية، تكرار، وتذكيرات.
- **جدول الإنجاز:** أقسام ← مواد أو مشروعات ← محاضرات، مع حساب التقدم.
- **المظهر:** فاتح، داكن، ومريح للعين، بالعربية والإنجليزية.
- **البيانات:** تخزين محلي مع إمكانية تصدير واستيراد نسخة احتياطية.

## للمطوّرين

المصدر الأساسي لواجهة التطبيق هو `index.html`. يتم تجميع جسر Capacitor من `src/native.js` إلى `www/native.js` أثناء البناء. ملفات Android الأصلية موجودة في `native/android/`، ويتم تثبيتها في مشروع Android المولّد بواسطة `tools/install_native_notifications.py`.

### فحوصات المشروع

```bash
npm install
npm run check
npm run build:native
```

يتطلب بناء APK وجود Android SDK وJava 21 وإعداد أسرار التوقيع المطلوبة في GitHub Actions.
